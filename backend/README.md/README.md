# Food Delivery Platform - Backend

## Project Description

The Food Delivery Platform is a Java-based backend project
developed for managing food ordering and delivery operations.

The system allows users to view restaurants, select food items,
add food to the cart, place orders, make payments, and track
delivery status.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- VS Code

## Backend Modules

### 1. User
Stores and displays customer information.

### 2. Restaurant
Stores restaurant details such as name and location.

### 3. FoodItem
Stores food name and price.

### 4. Cart
Allows users to add food items and calculates the total amount.

### 5. Order
Creates and displays order details.

### 6. Payment
Handles payment information and payment status.

### 7. Delivery
Updates the delivery status of an order.

### 8. DatabaseConnection
Provides a basic structure for future database integration.
